title: From one image to a full Store asset set
date: 2026-09-29
description: Windows Asset Creator turns a PNG or JPEG into a validated Microsoft Store and MSIX asset package.
category: Apps
---

Windows Asset Creator is now available for the tedious part of preparing a Windows app for release: making all the images fit the Store and package requirements.

Start with a PNG or JPEG and create a validated set of Microsoft Store and MSIX assets in one place. It is a small tool for removing a repetitive bit of release friction so you can get back to the app itself.

[Get Windows Asset Creator from the Microsoft Store](https://apps.microsoft.com/detail/9ppcx5fvpdn3?hl=en-US&gl=US).
