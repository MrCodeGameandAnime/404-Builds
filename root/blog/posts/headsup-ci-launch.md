HeadsUp CI is now available: a lightweight Windows app for keeping an eye on GitHub Actions without losing the thread of what is running where.

It brings repository and branch status, workflow jobs, and exact-commit CI results into one configurable HUD. The exact-SHA view helps connect a result to the commit it actually tested.

[Get HeadsUp CI from the Microsoft Store](https://apps.microsoft.com/detail/9nmls5ft4zrw?hl=en-US&gl=US).
